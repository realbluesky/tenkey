Mode

Practice marks each amount right or wrong. Exam hides that until the end — exam scores are the official personal bests.

  1. Read the amount in the box on the top check.
  2. Enter it on the 10-key. Trailing zeros after the decimal are optional (4 for $4.00, 73.7 for $73.70).
  3. Press + to add toward the total, and Tab to slide — either order.
  4. Shift+Tab pulls the last check back if you Tabbed too soon.
  5. Alpha and stray keys show on the display and must be corrected.

Meant for a numpad / 10-key. The top number row will still count, but it is not the intended interface.
